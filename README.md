# Portfolio de Marie-Merveille

Portfolio personnel développé avec React, TypeScript et Vite.

## Développement local

```sh
npm ci
npm run dev
```

## Build de production

```sh
npm run build
```

## Déploiement

Le site est publié avec GitHub Pages à l'adresse
https://merveillegms.github.io/Portfolio/. Chaque mise à jour poussée sur
`main` lance automatiquement le workflow **Deploy portfolio to GitHub Pages**.
